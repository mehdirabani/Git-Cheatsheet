دستورات کاربردی Git

دستور Git کارایی دستور
git --version نمایش نسخه Git نصب شده
git config user.name "name" تنظیم نام کاربری برای کامیت‌ها
git config user.email "email@example.com" تنظیم ایمیل برای کامیت‌ها
git config --list نمایش تمام تنظیمات پیکربندی Git
git init ایجاد مخزن Git جدید در پروژه جاری
git status نمایش وضعیت فایل‌ها (نسبت به آخرین کامیت)
git add "filename" اضافه کردن فایل خاص به مرحله stage برای رصد تغییرات
git add . اضافه کردن تمام فایل‌ها و پوشه‌های پروژه به stage
git commit -m "message" ثبت تغییرات به همراه توضیح (پیام)
git commit -a -m "message" ثبت خودکار فایل‌های track شده (بدون نیاز به add)
git log نمایش لیست کامل کامیت‌ها به همراه جزئیات
git log --oneline نمایش خلاصه کامیت‌ها (هر کامیت در یک خط)
git log --stat نمایش آمار تغییرات در هر کامیت (افزوده/حذف شده)
git log --graph نمایش شاخه‌ها به صورت گرافیکی
git log --graph --oneline نمایش گرافیکی خلاصه کامیت‌ها
git log --after="2023-10-12" نمایش کامیت‌های بعد از تاریخ مشخص (سال-ماه-روز)
git log --before="2023-10-12" نمایش کامیت‌های قبل از تاریخ مشخص
git log --author="name" نمایش کامیت‌های یک نویسنده خاص
git commit -am "message" معادل git commit -a -m "message"
git show commit-hash نمایش تغییرات یک کامیت مشخص (به جای $$$$$$ هش واقعی قرار دهید)
git config --local alias.lgo "log --oneline" ایجاد نام مستعار برای دستورات (مثال: با lgo جایگزین log --oneline)
git branch نمایش لیست شاخه‌های موجود
git branch branch-name ایجاد شاخه جدید با نام دلخواه
git switch branch-name تغییر به شاخه دیگر (جابجایی HEAD)
git branch -d branch-name حذف شاخه (فقط در صورت merged بودن)
git switch -c branch-name ایجاد شاخه جدید و جابجایی به آن در یک مرحله
git branch -m new-name تغییر نام شاخه فعلی
git merge branch-name ادغام شاخه دیگر با شاخه فعلی (Fast-forward یا merge commit)
git diff نمایش تفاوت بین working directory و آخرین کامیت
git diff --staged نمایش تفاوت بین stage و آخرین کامیت
git diff HEAD نمایش تفاوت working directory با آخرین کامیت
git checkout commit-hash جابجایی HEAD به کامیت قدیمی (حالت detached HEAD)
git log --all نمایش تمام کامیت‌ها در همه شاخه‌ها (حتی در حالت detached)
git checkout commit-hash -- filename بازگردانی یک فایل خاص به نسخه کامیت مشخص
git restore filename بازگردانی تغییرات یک فایل به آخرین کامیت (لغو تغییرات نکرده)
git restore --staged filename خارج کردن فایل از stage (معادل git reset HEAD filename)
git restore --source=commit-hash filename بازگردانی فایل به نسخه یک کامیت خاص (مشابه checkout)
git restore --source=HEAD بازگردانی تمام فایل‌ها به آخرین کامیت (لغو تغییرات نکرده)
git clean -fd حذف فایل‌ها و پوشه‌های untracked از پروژه (با احتیاط!)
git reset --soft commit-hash بازگردانی به کامیت مشخص؛ تغییرات در stage باقی می‌مانند (قابل بازگردانی با reflog)
git reset --mixed commit-hash بازگردانی به کامیت مشخص؛ تغییرات در working directory باقی می‌مانند
git reset --hard commit-hash بازگردانی کامل به کامیت مشخص (⚠️ خطرناک: تغییرات حذف می‌شوند)
git revert commit-hash ایجاد کامیت جدید برای معکوس کردن تغییرات یک کامیت قبلی (ایمن‌تر از reset)
