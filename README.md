## ✨ نمای کلی

این پروژه یک **مرجع سریع و گرافیکی** از دستورات Git است که به صورت یک جدول واکنش‌گرا طراحی شده. با استفاده از این ابزار می‌توانید:

- دستورات روزمره Git را سریع پیدا کنید
- کاربرد هر دستور را به زبان ساده ببینید
- از طراحی چشم‌نواز و حرفه‌ای لذت ببرید
- در تیم‌های خود از آن به عنوان مستند سریع استفاده کنید

## 🧭 راهنمای استفاده

<details>
<summary><b>📌 چگونه از این جدول استفاده کنم؟ (کلیک کنید)</b></summary>

<br>

1. **مشاهده دستورات**  
   جدول شامل دو ستون است: «دستور Git» و «کارایی دستور». به سادگی دستور مورد نظر را پیدا کنید.

2. **جستجو در صفحه**  
   از کلیدهای `Ctrl + F` (ویندوز) یا `Cmd + F` (مک) استفاده کنید و نام دستور را جستجو کنید.

3. **کپی کردن دستور**  
   روی هر `<code>` کلیک کرده و `Ctrl + C` بزنید. (به زودی قابلیت کپی خودکار با کلیک اضافه خواهد شد)

4. **حالت مطالعه**  
   اگر صفحه شلوغ به نظر می‌رسد، می‌توانید با ابزارهای مرورگر (مانند reader mode) یا زوم کردن، تمرکز بیشتری داشته باشید.

5. **ذخیره به صورت PDF**  
   در مرورگر گزینه `Print` (Ctrl+P) را انتخاب کرده و به عنوان PDF ذخیره کنید.

</details>

<details>
<summary><b>➕ چگونه یک دستور جدید به جدول اضافه کنم؟ (راهنمای مشارکت)</b></summary>

<br>

برای افزودن دستور جدید به این مستندات، کافیست مراحل زیر را انجام دهید:

1. فایل `pages/index.html` را باز کنید.
2. در بخش `<tbody>` جدول، یک سطر جدید به شکل زیر اضافه کنید:

````html
<tr>
  <td><code>git your-command</code></td>
  <td>توضیح فارسی دستور شما</td>
</tr>
````
project/
├── pages/
│   └── index.html          # صفحه اصلی جدول دستورات
├── assets/
│   ├── fonts/              # فونت‌های یکان باخ
│   │   ├── woff/
│   │   └── woff2/
│   └── styles/
│       ├── cssReset.css    # نرمال‌سازی پیش‌فرض مرورگرها
│       ├── fontFamily.css  # تعریف فونت یکان
│       └── style.css       # استایل‌های اصلی جدول و رنگ‌بندی
├── .gitignore              # فایل‌های نادیده برای گیت
├── LICENSE                 # مجوز MIT
└── README.md               # همین فایل

🤝 درخواست همکاری و مشارکت
ما از تمام توسعه‌دهندگان فرانت‌اند و علاقه‌مندان به Git دعوت می‌کنیم در بهبود این پروژه کمک کنند. راه‌های همکاری:

گزارش باگ: یک Issue جدید با برچسب bug باز کنید.

پیشنهاد دستور جدید: Issue با برچسب enhancement باز کنید و دستور + توضیح آن را بنویسید.

بهبود ظاهر: اگر ایده‌ای برای بهتر شدن طراحی (رنگ‌بندی، فونت، انیمیشن) دارید، Pull Request بزنید.

ترجمه به انگلیسی: اگر مایل به ایجاد نسخه انگلیسی جدول هستید، هماهنگ کنید.

فرآیند مشارکت کد
مخزن را Fork کنید.

یک Branch جدید بسازید:
git checkout -b feature/my-awesome-change

تغییرات خود را اعمال کرده و Commit کنید:
git commit -m "feat: توضیح تغییر"

Push کنید:
git push origin feature/my-awesome-change

یک Pull Request در گیت‌هاب باز کنید.

📌 تمام Pull Requestها باید به شاخه main ارسال شوند. حتماً پیشنهاد خود را به صورت واضح توضیح دهید.
